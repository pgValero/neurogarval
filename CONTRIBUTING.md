# Contributing

## Build the project

The site is generated by the script `scripts/build.py`. Run these commands from the repository root:

```bash
python -m pip install pyyaml markdown pillow
python scripts/build.py
```

The generated site is in `_site/`. To view it, open `_site/index.html` in a browser; do not open
`src/index.html` directly, because it still contains the unresolved markers and the pending contact data.

If you prefer [`uv`](https://docs.astral.sh/uv/), you can run the build without installing the
dependencies permanently:

```bash
uv run --with pyyaml --with markdown --with pillow python scripts/build.py
```

## prek hook

The hook configuration lives in `.pre-commit/`. Install the hook from the repository root with:

```bash
prek install --config .pre-commit/.pre-commit-config.yaml --force
```

From then on, `prek` runs automatically on every `git commit`.

To run all the hooks manually:

```bash
prek run --config .pre-commit/.pre-commit-config.yaml --all-files
```
